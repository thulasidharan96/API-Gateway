# Folder Structure

- `src/app/api` - FastAPI routers
- `src/app/core` - config/security/logging/telemetry/middleware setup
- `src/app/db` - models, repositories, alembic migrations
- `src/app/services` - business logic layer
- `src/app/middleware` - request middleware
- `tests` - unit and integration tests
- `docs` - architecture and ops documentation
